# CodeFlex Doubly Linked List in C

A menu-driven Doubly Linked List implementation using C programming.

## Features

- Create a doubly linked list
- Insert at beginning
- Insert at end
- Insert at a specific position
- Delete at beginning
- Delete at end
- Delete at a specific position
- Forward traversal
- Backward traversal
- Dynamic memory allocation
- Memory cleanup

## Language

C Programming

## How to Compile

```bash
gcc Menu.c -o dll
